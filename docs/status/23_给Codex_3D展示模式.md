# 23 给 Codex：3D「展示模式」——像发布会视频一样的拆解和漫游（11/14 18:50）

参考：Diletta 发的 DeepMind 发布会视频——深色背景、柔和光影、镜头连续运动、物体一层层拆开再合上、镜头穿进场景里漫游。
建筑版本就是：**一栋楼像手表爆炸图一样一层层剥开 → 合上 → 镜头飞进一个房间 → 在里面走一圈**。
这些画面要能直接录成我们的 2 分钟演示视频和 PPT 素材。
18 号做完后先做这个（排在 21 号前面）。只改 web/。不读 .env。不 push。每项截图或录屏自查后单独 commit。
用 data/ifc_models/bsc-esplanades_1807-ep-ar-v18.ifc 和 data/ifc_bench/ac20_arc.ifc 测。

## 1. 画面质感（P0）
- 「Showcase」开关（3D 区右上角）：打开后背景换成深色渐变（近黑 → 深蓝灰），地面一块接收阴影的圆盘
- 光：一盏斜上方的平行光投软阴影 + 环境光 + 半球光；开 SSAO 或近似的环境光遮蔽（three.js postprocessing 的 SAOPass / N8AO，选性能够的）
- 构件描边：在构件边缘画细线（EdgesGeometry 或后处理描边），有建筑线稿感
- 材质：按工种的配色降低饱和度、稍微哑光；被问到的构件（答案高亮）用发光的品牌黄（bloom），其他构件变半透明
- 性能：大模型时自动降级（关 SSAO / 描边），保持 30 fps 以上

## 2. 爆炸图：一层层剥开再合上（P0）
- 「Explode」做成动画：楼层按从上到下的顺序依次向上分开（每层间隔约一层楼高，缓动 easeInOutCubic，每层错开 120 ms），再按一次反向合上
- 「Peel」：同一层内按工种一层层剥：先把屋顶/楼板抬走 → 墙变成 20% 透明 → 露出家具和设备（水电管线用工种色发光）。每一步 0.8 s，可以按住空格一步步走
- 剥开状态下鼠标悬停一层，这层亮起来并显示楼层名和面积

## 3. 一键「导览」（P0，就是视频素材）
- 「Tour」按钮：自动播放一段约 40 秒的镜头运动，不需要人操作：
  1. 远景缓慢环绕整栋楼（8 s）
  2. Explode 拆开，镜头上移俯视（8 s）
  3. 合上，镜头推近选中的楼层，楼层以上淡出（6 s）
  4. 飞进一个有状态/留言的房间，房间名标签淡入（6 s）
  5. 第一人称在房间里慢慢转一圈（8 s）
  6. 拉回远景（4 s）
- 镜头路径用 CatmullRom 曲线插值，平滑无抖动；任何时候按 Esc 中断
- 底部字幕条（可关）：每一段配一句英文说明，例如「6 floors · 214 rooms · every count traceable」

## 4. 录成视频（P1）
- 「Record」：用 canvas.captureStream + MediaRecorder 把 Tour 录成 webm 下载（1920×1080，30 fps），录的时候隐藏界面上的按钮
- 「Hi-res screenshot」：2× 分辨率截图，透明或深色背景可选
