# 17 给 Codex：3D 查看器大改——按楼层看、按房间走进去（11/14 17:40）

Diletta 和建筑师实测：3D 现在只能从外面转着看，楼层分不清，进不了房间。这是演示的核心画面，优先级最高。
只改 web/。不读 .env。不 push。每项单独 commit；每项做完用浏览器打开下面 3 个模型截图自查，再 commit。
测试模型：data/ifc_bench/ac20_arc.ifc（多层住宅，有房间）、data/ifc_models/ 里任意一个带 IfcSpace 的模型、data/ifc_models/bsc-clinic_clinic-plumbing.ifc（只有管道）

## 1. 楼层（P0）
- 左侧竖排楼层列表，按标高从上到下排（屋顶在最上，地下室在最下），显示楼层名 + 标高 + 房间数。标高按模型里的真实值显示，单位 m，不要出现 -12.0m 这种看不懂的负数（如果模型整体偏移，就以最低楼层为 0 显示相对高度）
- 点一层 = 只显示这一层（上面的全部隐藏，下面的变成 15% 透明灰色做参照），镜头自动转到这一层的斜俯视角并对准
- 「Explode」开关：所有楼层沿竖直方向拉开间距，一眼看清有几层、每层是什么
- 「Plan view」按钮：正上方俯视当前楼层（正交相机），像平面图一样看

## 2. 房间（P0）
- 选中楼层后，每个 IfcSpace 房间中心浮着名字标签（房间名 + 编号 + 面积，来自 IFC 属性），标签太多时只显示镜头附近的
- 房间地面用半透明颜色块：按 /collab 的房间状态上色（built 绿、missing_wall 红、pending 黄，无状态浅灰）
- 鼠标悬停高亮房间，单击 = 镜头飞进这个房间（平滑动画 ~0.8 s），并打开现有的房间卡（状态、留言、照片）
- 侧栏房间列表（按楼层分组，可搜索），点名字同样飞过去

## 3. 走进去（P1）
- 「Walk」模式按钮：第一人称，眼高 1.6 m，WASD/方向键移动，鼠标拖动转头，滚轮调速度；Esc 退出回到环绕视角
- 进入 Walk 时从当前选中房间的中心出发；隐藏当前楼层以上的所有东西和天花板，避免挡住
- 不做碰撞也行，但不能穿到楼层下面：高度锁在当前楼层地面 + 1.6 m
- 左下角小地图：当前楼层的俯视轮廓 + 一个表示自己位置和朝向的小箭头

## 4. 操作提示（P1）
- 3D 区右下角一个「?」：列出操作方式（左键转、右键平移、滚轮缩放、双击对准、Walk 的按键）
- 第一次打开 3D 时显示 5 秒的浅色提示条：「Pick a floor on the left, then click a room to fly in. Press Walk to look around inside.」

## 验收
- npm run build 通过
- 截图自查：ac20_arc.ifc 能一层一层看；Explode 能看出几层；点一个房间能飞进去并看到房间卡；Walk 能在房间里转一圈
