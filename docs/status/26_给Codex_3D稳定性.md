## 1. 状态稳定（P0）
- 复现并修复：打开项目 → 切到别的页面/项目 → 再回来，3D 的样子不一样（楼层选择、Explode/Peel、Showcase、工种开关、相机、透明度残留）
- 规则：每次加载模型都从同一个确定的初始状态开始（全部楼层、未爆炸、非 Showcase、全部工种、Fit 视角）；卸载时彻底 dispose（几何、材质、动画帧、事件监听、轮询定时器）
- 加一个「Reset view」按钮：一键回到初始状态
- 连续做 5 次：打开 esplanades → 切到 swiss → 切回，截图对比必须一致；控制台不能有报错

## 2. 触控板和缩放（P0）
- 触控板：双指上下滑 = 缩放，但速度要慢且平滑（按 deltaY 归一化，区分鼠标滚轮的大步进和触控板的小连续值；每次事件缩放幅度封顶约 5%）；双指捏合（ctrlKey wheel）= 缩放；带惯性阻尼
- 缩放朝光标位置；缩放范围有上下限（不能穿进模型里，也不能缩到看不见）
- 右下角固定一组大按钮：＋ / － / Fit / Reset，每点一次缩放 20%，带平滑动画；旁边一个竖向滑杆
- 单击一个构件或房间：它成为旋转中心；双击：平滑拉近到它
- 没有鼠标也能平移：按住空格拖动 或 双指左右滑；方向键也能平移

## 3. 走路功能要让人找得到（P0）
- 「Walk」做成 3D 区左下角一个带图标和文字的大按钮（行走小人 + "Walk inside"），不要藏在工具条里
- 进入 Walk 后屏幕中下方显示半透明的按键提示（W A S D / 方向键移动，拖动转头，Esc 退出），5 秒后淡出，按 ? 再显示
- 触控板/无鼠标也能走：屏幕左下角一个虚拟摇杆（拖动移动），右侧拖动转头
- 点房间卡里的「Walk into this room」直接从这个房间开始走
- Walk 不能穿墙、不能掉出楼层（前方 0.3 m 射线碰撞即停；高度锁定楼层地面 + 1.6 m）

## 4. 穿模和闪烁（P0）
- z-fighting（面互相闪烁）：renderer 开 logarithmicDepthBuffer，或按模型包围盒动态设 near/far；重合面用 polygonOffset
- 相机不进墙里：环绕模式下相机与模型表面最小距离；near plane 0.05–0.1 m
