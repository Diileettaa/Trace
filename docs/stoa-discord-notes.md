# Stoa 在 Discord #stoa 的说明（截至 11/14 19:00 抄录要点）

- 评测用的图：混合格式；**最难的是扫描图（PDF 或 PNG），最难的问题集中在扫描图**
- 最终评测用未公开的图，但也会参考在公开数据集上的表现；**真实问题比数据集里的复杂**，是人写的
- 一栋楼可能有 8 张平面，一个项目可能有多栋楼/多套图。准确率只针对 1 张图评，但创新和真实影响看整个流程
- 题里不一定写明是哪张图/哪个视图 → 「按最好的用户体验做，界面可以交互」（让用户选图/楼层，或系统自己判断并说明）
- 评委会尽量适配各队界面；准确率只是评分的一部分
- 成本：按常识判断；每张图摄入几分钱没问题，10 美元一张就会扣分
- 回答可以比数据集的示例更长、更详细
- 门的计数：衣柜门也算门（Pyry from Stoa 的说法）
- 演示视频：录屏 + 旁白就可以
- 难题示例（13:41 发的，附 4 张图：英国特殊学校一层平面、美国 aw_078 两张、宿舍 daf_dorm 一张）：
  1. 不同区域的楼面面积
  2. 踢脚线延米
  3. 门窗计数
  4. 按类型（厚度、配筋）统计楼板面积
  5. 加分项：能看懂管道图
  - 「部分做出来也已经很厉害」
- 样图在 data/stoa_samples/（git 忽略，不提交、不拿来训练）
